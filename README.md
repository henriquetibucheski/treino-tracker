# 💪 Treino Tracker

App pessoal de acompanhamento de treinos — PWA em arquivo único, sem dependências.

- Registro de cargas com prefill da última sessão
- Streak semanal estilo Duolingo (meta: 3 treinos/semana)
- Periodização em blocos (jun–dez/2026) com variações de exercícios por fase
- Detecção de PR via 1RM estimado (fórmula de Epley)
- Gráficos de evolução por exercício e frequência semanal
- Funciona offline (service worker) e instala na tela de início do celular
- Dados no localStorage do dispositivo, com export/import JSON

Stack: HTML + CSS + JavaScript vanilla. Hospedado no GitHub Pages.
